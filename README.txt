PUTAR - Music Player Poster Lirik
==================================

Cara pakai:
1. Ekstrak zip ini.
2. Buka index.html di browser (Chrome/Safari).
   Untuk di HP: kirim folder ke HP lalu buka index.html, atau upload ke hosting
   gratis (Netlify Drop, GitHub Pages, Vercel).
3. Tekan play. Gunakan tombol bulatan (kanan atas) untuk mode rekam.

Pakai lagu sendiri:
- Buka menu (tiga garis) > "Pakai file sendiri".
- Pilih audio (mp3/m4a), lirik .lrc (opsional), dan cover (opsional).
- Lirik .lrc bisa diunduh dari lrclib.net.

Pencarian otomatis (cover + lirik):
- Tombol "Cari" memakai iTunes Search API (cover + preview 30 detik)
  dan LRCLIB (lirik sinkron). Butuh internet dan harus dibuka dari file
  lokal atau hosting sendiri.

Ganti font:
- Edit baris <link> Google Fonts dan variabel --ff di index.html.
  Font sekarang: Plus Jakarta Sans.

Catatan: lagu demo memakai nada sintetis dan lirik karangan sendiri.
Pastikan kamu punya hak untuk memakai lagu dan lirik yang kamu unggah.
